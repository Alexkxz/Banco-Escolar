# OTA-LAB histórico (archivado)

El firmware normal no integra OTA-ARQ.2 ni el instalador de laboratorio. Los fuentes, pruebas y configuraciones anteriores se conservaron en `archive/` para referencia histórica. No usar sus comandos o perfiles para construir o instalar firmware.

La única configuración PlatformIO activa es la raíz del proyecto (`platformio.ini`). OTA de producción permanece deshabilitada con `BANCO_OTA_ENABLED=0`.
